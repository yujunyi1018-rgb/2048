## 操作方式

- **桌面**: 方向键 ← ↑ → ↓
- **手机**: 滑动屏幕
- **按钮**: 新游戏 / ~~撤销~~（生活还在继续，请继续向前走吧！！）

## 本地运行

直接用浏览器打开 `index.html` 即可游玩。

## 部署到 GitHub Pages

1. 创建 GitHub 仓库
2. 将文件推送到 `main` 分支
3. 在仓库 Settings → Pages 中，选择 Deploy from main
4. 访问 `https://<用户名>.github.io/<仓库名>/`
