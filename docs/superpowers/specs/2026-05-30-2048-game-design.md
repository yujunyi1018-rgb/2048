# 2048 小游戏 - 设计文档

## 概述

一款基于 HTML/CSS/JavaScript 的 2048 变体游戏，部署在 GitHub Pages，用户点击链接即可游玩。

## 核心设计决策

- **纯前端单页应用** — 零依赖，无需构建工具，直接上线
- **5×5 棋盘** — 比经典 4×4 更大，提供更多操作空间
- **无限模式** — 不设 2048 胜利终点，持续比拼最高分
- **存档持久化** — 通过 localStorage 保存进度和最高分

## 游戏规则

- 5×5 棋盘，初始随机生成两个方块（2 或 4）
- 玩家通过方向键（键盘）或滑动（触屏）移动所有方块
- 相同数字的方块碰撞时合并为一个（数值翻倍），分数累加
- 每次移动后，在空位随机生成一个 2 或 4
- 棋盘填满且无相邻相同方块 → 游戏结束
- 无限进行，无胜利条件

## 功能清单

| 功能 | 实现方式 |
|------|---------|
| 5×5 棋盘渲染 | CSS Grid，方块用 div 表示 |
| 键盘控制 | `keydown` 事件监听方向键 |
| 触屏控制 | `touchstart`/`touchend` 计算滑动方向 |
| 方块合并动画 | CSS `transition` + `transform` |
| 计分板 | 当前分数 + 最高分（localStorage） |
| 当前最大数字 | 棋盘上最大方块值 |
| 新游戏按钮 | 重置棋盘和分数 |
| ~~撤销按钮~~ | **彩蛋**：点击弹窗「生活还在继续，请继续向前走吧！！」，不执行撤销 |
| 游戏结束检测 | 棋盘满 + 无可合并方块 → 弹结束提示 |
| 自动存档 | 每次移动后保存棋盘状态到 localStorage |
| 关卡恢复 | 页面加载时从 localStorage 恢复进度 |

## 视觉设计

- **风格**：白底简约扁平风，圆角方块，柔和阴影
- **配色**：2 到 131072 每个数字有对应的颜色渐变（参考原版 2048 色系）
- **响应式**：适配桌面和手机屏幕，棋盘居中显示

## 部署方案

1. 创建 GitHub 仓库
2. 推送代码到 main 分支
3. 开启 GitHub Pages（Settings → Pages → Deploy from main）
4. 获得 `https://<username>.github.io/<repo>/` 链接

## 游戏核心逻辑

- `Game` 对象：管理棋盘状态（5×5 二维数组）、分数、最高分
- `move(direction)`：核心移动逻辑，按方向遍历行/列，合并相同值
- `render()`：将棋盘状态渲染到 DOM
- `isGameOver()`：检测是否无空位且无相邻相等方块
- `addRandomTile()`：随机空位生成新方块（90% 概率 2，10% 概率 4）

## 边界情况

- 无空位时尝试移动 → 不执行，不生成新方块
- 移动后棋盘无变化 → 不生成新方块，不增加步数
- localStorage 数据损坏 → 检测异常，自动重置为新游戏
- 手机横屏 → 保持棋盘居中，自适应大小
- 游戏结束后继续操作 → 无响应，提示重新开始
